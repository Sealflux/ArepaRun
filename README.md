# ArepaRun
Run away from the people who want to eat you(you are an arepa), if they catch you, you die and have to start again until you beat the game´s final boss(Colombian soccer Player James Rodriguez) until you win the combat and beat the game.

Prior Requirements:
Our game doesn´t need any specific config or adjustment for people to be able to enjoy it, as it is avaiable on itch.io.

How to play:
The game features a title screen (done manually by us) where the player will hit the start button, and so a match will start, you use the keys Q and E to use the special powers of the arepa (Q:Spawn a spatula that launches you upwards so you can avoid the obstacles that spawn in game. E:Spawn a Transmilenio that can be used as a platform temporarily and stuns the first enemy seen in the game) To be able to use the Q power you will need to nail a quick time event to get the maximum altitude possible, but if you fail it you will only get a little boost(not enough to avoid obstacles).
